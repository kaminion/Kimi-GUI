# Kimi-GUI 0.8.9

Version 0.8.9 polishes two pieces of chrome: the changes popover always opens
where you expect it, and group headers trade their count for actions cleanly
on hover.

## The changes popover always opens above the input

The changed-files popover measured overflow before deciding which way to
open, so short file lists opened downward from the pill and covered the chat
input. It now always anchors its bottom edge just above the pill — a small
popup directly over the composer, every time.

![Changes popover anchored directly above the composer](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.9/docs/media/release-0.8.9-changes-popover-above.png)

## Group headers: count rightmost, actions on hover

The group header's invisible hover buttons occupied the right edge, pushing
the session count left, and the `+`, pencil, and `×` glyphs rendered at three
different sizes.

The count is now the rightmost element by default. Hovering (or tabbing into)
the header hides the count and reveals the three actions in its place — all
sharing one 18px geometry with a misclick buffer before the destructive `×`.
Keyboard users get the same swap via focus, and the draft-target badge still
appears ahead of the count while a group draft is pending.

![Group header at rest with the session count at the right edge](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.9/docs/media/release-0.8.9-group-count-default.png)

![The same header on hover: uniform new-chat, rename, and delete buttons](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.9/docs/media/release-0.8.9-group-actions-hover.png)
