# Kimi-GUI 0.7.0

Version 0.7.0 turns busy-hour typing into scheduled messages with a single
composer button, enlarges the changed-files summary, and limits the Skills
library to the paths Kimi actually reads.

## Schedule messages while Kimi is working

Typing a message while a turn is running no longer steers the active turn
immediately. The message is parked as a **Scheduled message** card that waits
for the current turn to finish, then runs automatically — one at a time, in
order.

While a card is waiting you can:

- **Edit** the text before it runs.
- **Run now** to deliver it immediately as a steering adjustment.
- **Cancel** to drop it entirely.

Scheduled cards survive switching to another conversation and back, on both
the Kimi CLI engine and the built-in engine. The draft you were typing is
also remembered per conversation, so nothing is lost when you move around.

The composer now has **one button**: it sends when idle, becomes **stop**
while Kimi is working with an empty input, and turns back into send as soon
as you start typing.

![Scheduled message card with edit, run-now, and cancel actions above the single composer button](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.7.0/docs/media/release-0.7.0-scheduled-message.png)

## A changed-files button you can actually hit

The **N files changed** summary above the prompt is now a full-size button
with a clear border, medium-weight label, and tabular added/deleted stats,
with stronger hover and pressed feedback in both themes. Selecting it still
opens the **Changes** tab in the right-side panel.

![Enlarged changed-files summary button with added and deleted line stats](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.7.0/docs/media/release-0.7.0-changes-button.png)

## Skills limited to the paths Kimi reads

The Skills library used to scan folders the Kimi CLI never loads
(`.claude`, `.codex`, `.config/agents`, legacy `.kimi`), so skills installed
there silently did nothing. The library now only scans the directories the
CLI actually discovers:

- User: `~/.kimi-code/skills` and `~/.agents/skills`
- Project: `.kimi-code/skills` and `.agents/skills`

New skills you add are installed into `~/.kimi-code/skills` (or the project
equivalent), so they take effect immediately. Every skill row also carries
an explicit **enabled/disabled** badge next to its name.

![Skills library showing only Kimi discovery paths with explicit state badges](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.7.0/docs/media/release-0.7.0-skills-kimi-paths.png)
