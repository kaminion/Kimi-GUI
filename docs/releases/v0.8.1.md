# Kimi-GUI 0.8.1

Version 0.8.1 restores the swarm pill to a one-click toggle whose state
you can read at a glance, and gives the changed-files button room to
breathe.

## Swarm: one click, unmistakable state

The swarm control is a flip toggle again — one click switches between ON
and OFF, no dropdown. The pill now always shows a small **switch**
(accent-filled with the knob on the right when ON, neutral with the knob
on the left when OFF) next to the ON/OFF chip, so the current mode is
visible without opening anything. Picking it on a fresh draft still
applies to the new chat, exactly like the other composer options.

![Composer options row with the swarm toggle switched ON](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.1/docs/media/release-0.8.1-swarm-toggle.png)

## A roomier changed-files button

The **N files changed** summary button gains extra padding all around,
so it reads as a full-size control instead of a tight chip. The OFF
state of the new swarm toggle is visible here too.

![Padded changed-files button with the swarm toggle in its OFF state](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.1/docs/media/release-0.8.1-changes-padding.png)
