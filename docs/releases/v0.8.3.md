# Kimi-GUI 0.8.3

Version 0.8.3 moves changed-file review into a tidy popover and stops
showing work you have already committed.

## Changed files, now a popover

The full-width strip above the prompt is gone. Changed files now appear
as a compact **N files changed +A −D** pill inside the composer options
row, next to model, thinking, permission, and swarm.

Clicking the pill opens a popover — same chrome and origin-aware
entrance as the option dropdowns — listing every changed file with its
own added/deleted counts. Selecting a file still opens its detail in the
**Changes** tab.

![Changed-files popover open above the composer options row](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.3/docs/media/release-0.8.3-changes-popover.png)

![Compact changed-files pill in the options row](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.3/docs/media/release-0.8.3-changes-pill.png)

## Committed work drops out of the list

The summary used to keep every file the session ever touched, even after
you committed and pushed. In a git repository, files that are clean in
`git status` now disappear from the pill, the popover, and the Changes
tab — what you see is only what is still uncommitted. Edit a file again
and it comes straight back. Sessions outside a git repository behave as
before.
