# Kimi-GUI 0.8.7

Version 0.8.7 fixes three pieces of conversation chrome: question options are
readable again, scheduled messages keep their place at the bottom of the
transcript, and Stop no longer strands a queued message.

## Question options breathe

AskUserQuestion option rows were unstyled, so the radio button (or checkbox)
sat flush against its label — hard to read and easy to misclick. Options are
now proper rows with an 8px gap between the glyph and the text, a hover
highlight, an accent-checked control, and a styled **권장** (Recommended)
badge.

![Question modal with radio options spaced away from their labels](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.7/docs/media/release-0.8.7-question-options.png)

## Scheduled messages stay at the bottom

A scheduled message card belongs at the very bottom of the transcript, but
new rows appended after it: the live **작업하는 중…** (Working…) row of the
next turn, optimistic user echoes, late message rows, and system notes all
landed below the card and pushed it up. Every append now moves the scheduled
cards back to the bottom, so a running turn can never cover or reorder them.

![Scheduled message card parked below the live Working row](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.7/docs/media/release-0.8.7-scheduled-bottom.png)

## Stop runs the scheduled message next

Stopping a turn used to interrupt the work but leave the scheduled message
parked indefinitely. Stop now hands the session to the queue: the interrupted
turn unwinds completely, then the oldest scheduled message starts
automatically as its own turn. If the interrupted turn cannot unwind, the
queue is left untouched rather than dropping the message.

## Verification
