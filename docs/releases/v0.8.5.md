# Kimi-GUI 0.8.5

Version 0.8.5 makes sidebar groups easier to manage: renaming a group is now
discoverable, and starting a chat inside a group shows exactly where the
conversation will land. It also tightens two pieces of transcript chrome.

## Rename groups from the group header

Group rename used to exist only as a double-click on the group name, which was
impossible to discover. A pencil button now rides the group header's hover
actions — between the new-chat `+` and the delete `×` — and opens the same
inline name edit as double-clicking.

![Group header hover actions with the rename pencil between new-chat and delete](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.5/docs/media/release-0.8.5-group-rename-hover.png)

The inline edit keeps its existing behavior: `Enter` commits, `Escape`
restores the previous name, and an empty name keeps the old one.

![Renaming a group through the inline input](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.5/docs/media/release-0.8.5-group-rename-edit.png)

## Group drafts show where the chat lands

Clicking `+` on a group starts a draft that is only filed into the group when
the first message is sent. Until now nothing marked that pending target. While
the draft is open, the destination group carries an accent highlight and a
**새 대화** (New chat) badge in the sidebar, and the draft workspace row above
the composer adds a **그룹** (Group) chip naming the target. Selecting another
conversation clears the marker, and the chip disappears once the session is
created and assigned.

![Draft target group marked in the sidebar and named above the composer](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.5/docs/media/release-0.8.5-group-draft-target.png)

## Transcript chrome fixes

- The floating **생각하는 중…** (Thinking…) header of an open process block now
  pins flush to the top of the transcript while scrolling. An 8px offset used
  to leave a see-through strip above the header where long thinking streams
  scrolled by.
- The group header's `+` and destructive `×` buttons grew from 16px to 18px
  with an 8px gap between them, putting a misclick buffer between creating a
  chat and deleting a group.
