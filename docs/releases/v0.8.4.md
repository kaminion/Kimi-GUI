# Kimi-GUI 0.8.4

Version 0.8.4 makes installed Skills easier to find and refresh, and keeps
Thinking disclosures visually attached to the assistant turn they explain.

## Search and refresh installed Skills

The main-sidebar Skills manager now searches locally across:

- Skill name and description.
- Installed path and discovery family.
- Current-project or all-project availability.
- Enabled or disabled state.

Every search term must match, so queries such as `review project` quickly
narrow a larger library. The result summary reports the filtered and total
counts, and a dedicated empty state suggests which fields can be searched.

**Refresh installed folders** performs a fresh scan of the Kimi Code and shared
Agents discovery locations. This picks up Skills or metadata changed outside
Kimi-GUI without restarting the app, while preserving the active search.

![Skills filtered to two review entries after refreshing the installed folders](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.4/docs/media/release-0.8.4-skills-search.png)

## Thinking stays with its answer

Kimi may persist one assistant turn as several adjacent messages while it
alternates between thinking, tools, and answer text. Those chunks previously
received the same spacing as unrelated messages, which made collapsed Thinking
rows look detached from the surrounding response.

Consecutive assistant chunks now use an 8px gap, and a Thinking disclosure uses
4px before its answer inside the same message. The normal 16px message rhythm
and 24px boundary before a new user turn remain unchanged, preserving clear
conversation structure.

![Consecutive Thinking disclosures and answers grouped into one compact assistant turn](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.4/docs/media/release-0.8.4-thinking-rhythm.png)
