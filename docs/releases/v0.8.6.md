# Kimi-GUI 0.8.6

Version 0.8.6 keeps the change totals in view while reviewing changed files:
the popover above the composer now opens with the same summary the pill
reports.

## Change totals lead the popover

The changed-files pill in the prompt options has always reported **파일 N개
변경됨** (N files changed) with the accumulated `+`/`-` line counts, but the
popover that opens from it listed only per-file rows — the overall numbers
disappeared the moment you started reviewing.

A summary header now leads the popover with the same totals, so the file list
never loses the big picture. The header refills live alongside the rows as
files are committed away or re-edited, and per-file rows still jump straight
to the file's diff in the **Changes** tab.
