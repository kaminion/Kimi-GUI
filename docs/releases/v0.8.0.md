# Kimi-GUI 0.8.0

Version 0.8.0 makes every composer option available before the first
message is sent, and lets you start a conversation directly inside a
sidebar group.

## Set the options before the conversation exists

Previously the model, thinking level, permission mode, and swarm pills
only worked after a session existed — a brand-new chat could not be
configured until the first message went out.

All four pills are now selectable on a fresh draft. Your picks are marked
with an **Applies to the new chat** hint and applied over the Settings
defaults the moment the session is created, so the very first answer
already uses the model, thinking level, and permission mode you wanted.

The **swarm** pill is now an explicit ON/OFF dropdown with a description
of each mode instead of an ambiguous flip toggle (the daemon API exposes
only a boolean swarm mode, so no agent-count presets are offered). The
options row is reordered to **model → thinking → permission → swarm**,
keeping the always-available pills together ahead of the engine-specific
one.

![Fresh draft composer with the reordered options row and an open dropdown](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.0/docs/media/release-0.8.0-draft-options.png)

## Start a chat inside a group

Custom sidebar groups gained a hover **+** action next to delete. It
opens a new chat that is filed into that group as soon as the first
message creates the session — no more dragging the conversation into
place afterwards. Plain new chats (the toolbar button or ⌘N) stay
ungrouped.

![Custom group header showing the new-chat and delete hover actions](https://raw.githubusercontent.com/kaminion/Kimi-GUI/v0.8.0/docs/media/release-0.8.0-group-new-chat.png)
